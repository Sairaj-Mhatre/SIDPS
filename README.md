## Security Incident Detection and Prevention System (SIDPS). 

The original scope of SIDPS aimed to analyse both network traffic and system processes, but in this iteration, we focus on monitoring network traffic exclusively.

The system captures, processes, and analyses incoming and outgoing network packets to detect potential threats, providing real-time insights into network behaviour. 

By leveraging advanced machine learning techniques and enhanced datasets like CICIDS2017 , SIDPS aims to detect anomalous traffic that could indicate an ongoing attack.
